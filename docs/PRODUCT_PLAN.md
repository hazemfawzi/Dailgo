# خطة إصدار Dailgo

حالة الكود في فرع `codex/consistent-arabic-workflow`. التنفيذ المحلي لا يعني نشر التغييرات أو تفعيل خدمات خارجية على السيرفر. كل بنود الخطة ضمن الإصدار، مع بوابات تفعيل منفصلة للخدمات التي تحتاج حسابات أو أجهزة.

## الإصلاحات وتجربة الاستخدام

| البنود | ما يقدمه الكود |
| --- | --- |
| RTL والنص المختلط | اتجاه تلقائي للنصوص والرسائل والعناوين؛ مراجعة الموبايل العربي |
| الأرقام والتواريخ والجمع | تنسيق مركزي حسب اللغة، وصيغ جمع عربية؛ الحفاظ على قيم حقول التاريخ القياسية |
| بداية الأسبوع | إعداد الحساب نفسه في التقويم والأسبوع والرئيسية |
| الإضافة والمساعد | محلل مشترك، أرقام عربية، أوقات عامية، مجال مقترح، ومعاينة الافتراضات قبل الحفظ |
| مطابقة المهام | تجاهل المسافات مع اقتراحات عند عدم وجود تطابق؛ لا تعديل تلقائي لتطابق تقريبي |
| المحادثات | ترجمة الردود المحلية عند العرض، ومعالجة الرد القديم المعروف؛ رد النموذج الحر يحتفظ بلغته الأصلية |
| التحديثات المفتوحة | محاولة إعادة تحميل واحدة عند فقدان ملف شاشة بعد النشر، مع انتظار الحفظ وحماية النماذج المفتوحة |
| الاختصارات | N مهمة، / بحث، F تركيز، Ctrl/Cmd+K مساعد وسجل تغييرات |
| تراجع | مهلة 20 ثانية للإنجاز والأرشفة؛ حماية التعديلات اللاحقة والمهام المتكررة |
| المهام المتكررة | يومي وأسبوعي وشهري، فاصل ونهاية اختيارية؛ إنشاء التالية عند الإنجاز |
| قوالب الأهداف | صحة وتعلم وادخار، مراحل ومهام بمعاينة؛ متاحة بعد معالج البداية أيضًا |
| الدورة اليومية | تخطيط الصباح، قرارات المتأخر، تركيز مرتبط بمهمة، مراجعة مسائية وأسبوعية ورادار المجالات |

الإصلاحات السابقة للشريط، وضع الليل، التقويم، تحذير المرحلة بعد الهدف، فصل التنفيذ عن الاستحقاق، إغلاق الهدف وتاريخ الكارت محفوظة. اختبارات الحساب والحذف والاستعادة والتصدير والروتين والتركيز تعمل على قواعد مؤقتة، لا على بيانات المستخدم.

## الإضافات

| الميزة | التنفيذ وحدود التفعيل |
| --- | --- |
| Claude | API على السيرفر، سياق محدد وذاكرة، تقسيم أهداف وتخطيط، معاينة وتأكيد وتراجع، حدود يومية عامة ولكل حساب. يحتاج مفتاحًا وميزانية على السيرفر؛ الاختبارات تستخدم مزودًا وهميًا |
| بريد وPush | اختيار صريح، تحقق البريد، تذكيرات مهام ومواعيد ومراجعات، سجل يمنع التكرار. يحتاج SMTP وVAPID واختبار وصول فعلي |
| Google Calendar | ربط OAuth، رموز مشفرة، استيراد بمعاينة وتصدير صريح وفصل الربط. يحتاج مشروع Google وإعداد الموافقة والتحقق الحي |
| الصوت | تحويل متاح حسب دعم المتصفح، نص قابل للتحرير ومعاينة؛ لا إرسال أو حفظ تلقائي |
| Widget | صفحة اليوم ورمز قراءة فقط قابل للإلغاء، ومصدر Android وiOS مع CI منفصل. بناء SDK والتوقيع والأجهزة الفعلية بوابات قبول مستقلة |
| العادات والإحصائيات | Streak يحترم أيام الروتين، إنجاز ووقت تركيز وتوزيع المجالات |
| شريك محاسبة | رابط هدف محدود الصلاحية وقابل للإلغاء، ملاحظات اختيارية وتعليقات يراجعها المالك |
| العائلة | حسابات مدعوة مستقلة، مهام مشتركة وإسناد وتراجع، تصدير ومعاينة استيراد منفصلان عن النسخة الشخصية |
| المالية | ميزانية شهرية ومصروفات وأهداف ادخار؛ مبالغ بوحدات العملة الصغرى، دون خلط العملات |
| الصلاة | اختيارية، طرق حساب ومذهب وإحداثيات يحددها المستخدم، ومواعيد على الرئيسية |
| Pro | مسار اشتراك اختياري وحدود إضافية؛ الدفع معطل افتراضيًا. Claude لحساب المالك لا يحتاج بوابة دفع |

## بوابات الإصدار

1. اجتياز البناء واختبارات المجال والسيرفر والميزات والمتصفح وحزمة الإنتاج والنشر؛ فحص CI بعد دفع الفرع.
2. مراجعة ودمج الفرع؛ نشره عبر المسار القائم مع نسخة احتياطية والحفاظ على المشاريع الأخرى.
3. إعداد الخدمات المطلوبة فقط في `/etc/personal-os.env` وفق [دليل التكاملات](../deploy/INTEGRATIONS.md). لا توضع المفاتيح في المستودع أو المحادثة.
4. اختبار Claude والبريد وPush وGoogle على الحسابات الفعلية بعد الإعداد؛ لا تعتبر الاختبارات الوهمية إثبات تفعيل.
5. اجتياز CI الخاص بالـ Widget، ثم التوقيع والتجربة على الجهاز المقصود وفق [دليل الأجهزة](../native/README.md).
6. المدفوعات تظل معطلة حتى اختيار نموذج البيع والمزود وتفعيله عمدًا.

لا توجد مزامنة كتابة دون اتصال؛ انقطاع الشبكة يوقف الحفظ. التصدير الشخصي لا يضم بيانات مساحة العائلة، ولها تصدير مستقل. النسخة الاحتياطية للسيرفر ضرورية قبل ترقية أو رجوع إصدار.

## متابعة مراجعة ٢٨ أكتوبر

تم التحقق أن الإصدار المنشور `838c486` يضم PR #4 وتعديل Android؛ رقم الميرج ليس نسخة قديمة من الفرع.
إصلاحات المتابعة على فرع `codex/oct28-review`، وتحتاج مراجعة ودمج ونشر مستقلين:

- ترقيم النتائج بالأصفار العربية، وتاريخ ترحيل المراجعة المسائية، وموعد رسائل المساعد بنفس تنسيق التاريخ والوقت المحلي.
- إبقاء أرقام CSS وقيم حقول التاريخ بصيغتها التقنية؛ التنسيق المحلي يخص العرض.
- إعداد بداية الأسبوع ظاهر في التقويم وخطة الأسبوع. الافتراضي للمساحة العربية الجديدة السبت، مع الحفاظ على اختيار الحسابات القائمة.
- الخطة الحالية تتبع إعداد الأسبوع الجديد؛ الخطط السابقة تبقى قابلة للفتح بحدودها الأصلية من قائمة الأسابيع المحفوظة، مع توضيح الاختلاف.
- المجال المقترح ظاهر وقابل للتحرير في معاينة المساعد، ويُستخدم عند التأكيد؛ المجال المحدد في نطاق المحادثة له الأولوية.
- ترجمة الردود المحلية القديمة المعروفة وقت العرض دون تغيير النص المخزن أو رسائل المستخدم.
- رقم نسخة الواجهة داخل نافذة التثبيت، وتنبيه تحديث ظاهر عند تجهيز نسخة جديدة. تطبيق التحديث ينتظر انتهاء الحفظ.

حقل التكرار موجود مباشرة في نموذج «مهمة جديدة» قبل «تفاصيل أكثر»، واختبار المتصفح يغطي ظهوره بالعربي. المساعد المحلي يوضح صراحة إذا كان Claude غير مفعّل على السيرفر؛ وجود التكامل في الكود لا يغني عن إعداده في ملف البيئة الخاص وفق دليل التكاملات.
